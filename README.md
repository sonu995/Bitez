**Bitez** is a modern, responsive food delivery and daily tiffin subscription platform crafted for students, professionals, and food lovers. It seamlessly blends daily mess subscription management with instant meals ordering.

---

## ✨ Features

- 🍲 **Mess & Tiffin Subscription Plans**: Flexible daily, weekly, and monthly tiffin meal plans with customizable meals (Breakfast, Lunch, Dinner).
- ⚡ **Instant Food Ordering**: Browse menu items, categories, add custom items to cart, and checkout with instant orders.
- 📱 **Mobile-First Experience**: App-like bottom navigation, streamlined mobile header, and touch-optimized UI.
- 📍 **Live Order & Complaint Tracking**: Track food delivery stages and customer support complaints in real time.
- 🔐 **Authentication & Dashboard**: Secure user registration, login, profile management, and order history.
- 🛡️ **Admin Panel**: Manage tiffin plans, customer subscriptions, menu items, and incoming orders.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Routing & State**: React Router v7, React Context API
- **Charts & Analytics**: Recharts
- **Hosting**: Netlify ([bitezzz.netlify.app](https://bitezzz.netlify.app/))

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/sonu995/Bitez.git
cd Bitez/landing_page_redesign
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
